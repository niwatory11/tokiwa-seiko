# 設計根拠 — 市場調査の原則と「常盤精工」の対応

本プロジェクトは、Instagram Reelsで紹介されている商業Webサイト12件の市場調査(業界横断・重複排除)から抽出した設計原則をもとに設計しています。調査の生データには第三者の投稿情報が含まれるため公開リポジトリには含めず、本書では抽象化した原則と、それを本サイトがどう実装しているかだけを記録します。

## 調査から得た設計軸

調査したサイトは大きく2軸に分かれました。

| 軸 | 有効な業界 | 信頼の作り方 |
|---|---|---|
| 世界観・情緒型 | 高級不動産・高級車・飲食など高級商材 | 余白・質感・トーンを「体験」させる |
| 明快さ・信頼型 | 製造B2B・フィンテック・SaaS | 情報階層と検証可能な具体で語る |

本作は**明快さ・信頼型**を採用しました。姉妹作「菓寮 月白」(世界観・情緒型)と対になる2作目として、B2B製造業のコーポレートサイトを題材に、情報設計とコンバージョン設計の実力を示すことを目的としています。

## 原則 → 実装の対応

### 1. B2Bは世界観より情報階層と摩擦の少ない導線が信頼を生む

製造B2Bの調査事例では、断定的な価値提案コピー+整った情報階層+見積もり導線の組み合わせが有効でした。

- 断定コピー: 「0.01mmを、あたりまえに。」(数値だけ等幅+常盤色で組み、「精度が主役」を書体で言う)
- ヒーロー直下に「事実の帯」(加工精度・最小ロット・5軸・見積回答日数)— いずれもページ内の設備・加工内容で裏付けられる能力値のみ
- 見積もりCTAはヘッダー右端に常設+ヒーロー+フロー直後の3箇所(B2Bの複数配置の定石)

### 2. 信頼は「検証可能な具体」で作る(架空実績は使わない)

調査では、実測値や検証可能なメッセージを提示するサイトが最も説得力を持っていました。ただし本作は架空企業のため、取引実績・顧客数などの「成果の数値」は一切書きません。代わりに:

- 設備一覧をスペック表(加工範囲・測定精度)で提示 — ページ内で自己検証できる能力値
- 加工範囲は数字の列だけでは大きさを比べにくいので、四台を同じ縮尺で並べた図を表の前に置く。発注側がまず知りたい「うちの部品は載るか」に、図で答える
- 品質保証は「恒温検査室 20±1℃」「検査成績書の標準添付」など運用の具体で語る
- 加工例には「コンセプト提示用の架空事例」であることを明記

### 3. 業界クリシェを避けて独自性と信頼を両立する

調査では「業界の常套表現を意図的に外した配色」が独自性と信頼を両立させる好例として観察されました。

- 製造業定番の紺+オレンジ、工場写真、歯車アイコンを不使用
- 代わりにB2Bの共通言語である「機械図面」をデザイン言語化: 方眼・寸法線・公差表記・表題欄・図番
- 配色は社名と同源の伝統色「常盤色」(常緑=変わらない品質)を単一アクセントとして規律。朱色は検印スタンプとエラーのみ
- 加工例は写真ではなく自作SVGの機械図面(二面図・断面ハッチング・寸法線)

### 4. ヒーローは「短いコピー+主役ビジュアル+明確な次アクション」

- 業種の即時理解: 見出しの上に「精密切削加工 — 東京・大田区の町工場」を明示
- 主役ビジュアル: 方眼と表題欄(図面の様式そのもの)
- 具体的な動詞句CTA: 「図面から見積もりを依頼する」
- 架空企業の注記は表題欄の「注記」行として意匠に統合(フッターにも平文で明記)

### 5. CTAは「理解が最高潮に達した直後」に置く

- 見積もりの流れ(4ステップ)を理解した直後にフォームを配置
- 設備・品質保証で能力を確認した読者がいつでも動けるよう、ヘッダーCTAを常設

### 6. 1セクション1メッセージ/モーションは目的がある箇所のみ

- 対応加工→設備→品質保証→加工例→会社概要→見積もりと、1セクション1トピックで積み上げる
- 演出は「製図の手つき」(リビール/SVG線画/罫線ドロー/段差フェード/検印/ホバー色変化)に限定し、製図の順序=様式→罫線→記入を時間軸に翻訳する。`prefers-reduced-motion` で全停止(ナビの現在地表示のみ機能として維持)。装飾的な3D・グラデーションは不使用(調査で「AI量産物に見える主因」とされたパターンの回避)

## 採用しなかった知見とその理由

- **没入型WebGL**: 世界観の演出が目的の高級商材向け。B2Bの本作では速度と明快さを優先し不採用
- **信頼バッジ・星評価**: 実在の評価サービスのバッジは架空企業では虚偽表示になるため不使用。Concept Projectの注記で代替
- **ダークテーマ**: 調査で飽和が指摘された様式であり、図面=白地というコンセプトにも反するため不採用
