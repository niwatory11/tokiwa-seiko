# CrowdWorks ポートフォリオ掲載用説明文 — 常盤精工

## 作品タイトル

架空B2B製造業「常盤精工」コーポレートサイト(Concept Project)

## 短い説明(100文字程度)

架空の精密部品加工会社のコーポレートサイトです。機械図面の様式(方眼・寸法線・公差・表題欄)をデザイン言語化し、React+TypeScriptで見積もりフォームまで実装しました。

## 詳細な作品説明

B2B製造業(精密切削加工の町工場)を題材にした、架空企業のコンセプトサイトです。実案件を想定し、企画・情報設計・コピーライティング・デザイン・実装・テストまでを一人で担当しました。

商業サイト12件の市場調査から「B2Bは情報階層と摩擦の少ない導線が信頼を生む」「信頼は検証可能な具体で作る」という原則を抽出し、設計に反映しています。

- ファーストビューで業種・対応範囲・次アクション(見積もり依頼)が数秒で伝わる構成
- 設備スペック表・対応材質表・品質保証体制など、B2Bの意思決定に必要な情報を階層立てて提示
- 加工機四台の加工範囲を同じ縮尺で描いた比較図(A4用紙を重ねて、部品が載るかどうかの目安にできる)
- 加工方法ごとの略図(図面の線の使い分けで描いた自作SVG)
- 加工例は写真ではなく自作SVGの機械図面(二面図・寸法線・公差表記)で表現
- 見積もり依頼フォームはフロントエンドバリデーション付き(必須・形式・納期の境界検証、エラーサマリー、キーボード・スクリーンリーダー対応)

「常盤精工株式会社」は実在しない架空企業であり、その旨をサイト内に明記しています。

## 想定クライアント

製造業・建設業・士業など、信頼性と情報の明快さが重要なBtoB企業。コーポレートサイトの新規制作・リニューアル案件。

## 担当範囲

企画 / 情報設計 / コピーライティング / デザイン / コーディング / テスト / デプロイ(すべて個人制作)

## 使用技術

React 19 / TypeScript(strict) / Vite 8 / CSS Modules + デザイントークン / Vitest + Testing Library(テスト25件) / GitHub Actions(CI/CD) / GitHub Pages

## 工夫した点

- 機械図面の様式をデザイン言語化(方眼・寸法線・表題欄・図番・等幅数字)し、製造業サイトの定番表現(紺+オレンジ・工場写真)を使わずに業種らしさと独自性を両立
- 架空企業のため成果数値を書かず、「設備スペック」「品質保証の運用」など検証可能な具体だけで信頼を設計
- 見積もりフォームのバリデーションを純粋関数に分離し、日付境界(7日後〜180日後)を含む25件の自動テストで担保
- アクセシビリティ(フォーカストラップ、エラーサマリーからのフォーカス移動、reduced-motion対応)

## レスポンシブ対応

360 / 375 / 768 / 1024 / 1440px で検証済み。設備表・図面・フォームはモバイル専用レイアウトに組み替えています。
